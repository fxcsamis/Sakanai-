# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within Arise, please do not disclose it publicly.

Instead, report it privately by email:

[rjsharmase@gmail.com](mailto:rjsharmase@gmail.com)

Please include:

* A description of the issue
* Steps to reproduce
* Potential impact
* Screenshots or logs (if applicable)

## Response

Reasonable efforts will be made to investigate and address legitimate security concerns in a timely manner.
